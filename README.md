# HTML/CSS: афиша мероприятий

Практическое задание по первым трём лекциям курса Frontend разработки ИТМО. Основная тема — [«Модель отображения. Часть 1»](https://itmo-frontend-lectures.vercel.app/1-sem/html/3-view/index.html).

Сверстайте страницу с тремя карточками мероприятий. Тематику, названия и оформление выберите самостоятельно.

## Что должно быть на странице

Заголовок страницы и три карточки. В каждой карточке:

- название мероприятия;
- дата;
- описание;
- несколько тегов;
- ссылка «Подробнее».

Сделайте описания разной длины: одно короткое, другое на несколько строк.

## Требования

1. Используйте осмысленную HTML-разметку: основной контент, самостоятельные карточки, заголовки, абзацы и ссылки. Стили вынесите в отдельный CSS-файл.
2. Ограничьте ширину общего контейнера значением `960px` и расположите его по центру через автоматические горизонтальные отступы.
3. При ширине окна `1200px` карточки должны располагаться в один ряд с промежутками. Используйте `inline-block`; Flexbox, Grid и абсолютное позиционирование в этой работе не применяются.
4. Ширина каждой карточки **вместе с рамкой и внутренними отступами — ровно `300px`**. Внутренние отступы — `20px`, рамка — `2px`.
5. Высота карточки определяется содержимым. Увеличение описания не должно приводить к наложению или обрезанию текста.
6. Теги оформите как небольшие плашки с помощью `inline-block`. Для ссылки предусмотрите изменение оформления при наведении.

## Два эксперимента

### Размеры карточки

Переключите карточку с `border-box` на `content-box`, сохранив остальные значения. Сначала рассчитайте её новую внешнюю ширину, затем проверьте результат в инструментах разработчика.

### Схлопывание отступов

Создайте отдельный пример из двух соседних блочных элементов в обычном потоке: у первого `margin-bottom: 24px`, у второго `margin-top: 40px`. Объясните получившееся расстояние между ними.

## Что сдать

- HTML-файл страницы.
- Отдельный CSS-файл и используемые изображения, если они есть.
- Короткие ответы по экспериментам: прогноз, фактический результат и объяснение.
