# Ответы по экспериментам

## Размеры карточки

Прогноз: с `border-box` внешняя ширина равна 300px. В неё уже входят внутренние отступы и рамка. При переключении на `content-box` значение `width` задаёт только ширину содержимого. Внешняя ширина станет 300 + 20 * 2 + 2 * 2 = 344px.

Для проверки у зимней карточки в инструментах разработчика нужно заменить `box-sizing: border-box` на `content-box`, сохранив остальные свойства.

Фактический результат: в браузере измерены 300px для `border-box` и 344px для `content-box`. Прогноз подтвердился. Увеличенная карточка больше не помещается в один ряд с двумя остальными, поэтому последняя переносится на следующую строку. После возврата к `border-box` исходные размеры и расположение восстанавливаются.

## Схлопывание отступов

Прогноз: между блоками будет 40px. Вертикальные отступы соседних блочных элементов в обычном потоке схлопываются: из двух положительных отступов остаётся больший, а не их сумма.

Фактический результат: измеренное в браузере расстояние между границами блоков - 40px. Прогноз подтвердился.
