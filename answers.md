# Ответы по экспериментам

## Размеры карточки

Прогноз: при `border-box` общая ширина карточки равна 300 px. При переключении на `content-box` ширина содержимого останется 300 px, а padding и рамка добавятся снаружи.

Результат в DevTools проверен, что `box-sizing` равен `content-box`, ширина содержимого 300 px, padding 20 px с каждой стороны, рамка 2 px. Внешняя ширина по Box Model 344 px. Это совпадает с расчётом: `300 + 20 × 2 + 2 × 2 = 344 px`.

## Схлопывание отступов

Прогноз: расстояние между блоками будет 40 px.

Результат: между соседними блоками остаётся больший из двух вертикальных отступов: `max(24 px, 40 px) = 40 px`. Отступы схлопываются.
